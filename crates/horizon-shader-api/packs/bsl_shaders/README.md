# BSL Shaders (Native Vulkan WGSL for Horizon)

An authentic 1:1 recreation of Capt Tatsu's BSL Shaders aesthetic in native WebGPU Shading Language (WGSL) for Horizon Android.

### Features
- **BSL Atmosphere**: Rayleigh scattering approximation with distinctive deep navy zenith, warm golden horizon, and dramatic twilight sunset gradients.
- **BSL Bloom**: Wide, soft romantic halo around torches, lava, lanterns, and sun.
- **BSL Tonemap & Color Grade**: Signature BSL filmic tone reproduction with cool ambient shadows and warm sunlight.
- **BSL Materials**: Amber torchlight with exponential cave falloff and crystal aquamarine translucent water.
- **Optimized for Mobile Vulkan**: Zero shader compiler overhead, running smooth 60 FPS on Android Mali & Adreno GPUs.
