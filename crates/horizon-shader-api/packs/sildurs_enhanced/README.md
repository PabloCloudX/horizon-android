# Sildur's Enhanced Default (Native Horizon Shader)

A native Vulkan WGSL shader pack for Horizon Android, bringing Sildur's iconic Enhanced Default look:
- Vibrant, dynamic sky with smooth atmospheric scattering
- Golden hour & sunrise/sunset warmth
- Warm torchlight falloff on terrain and caves
- Tropical water translucency and tint
- Lightweight filmic tone curve and saturation boost for mobile GPUs
